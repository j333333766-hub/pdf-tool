# PDF 종합툴 — 교사용 PDF 작업대

설치 없이 브라우저에서 바로 쓰는 PDF 작업 도구입니다. 파일은 서버로 전송되지 않고 내 컴퓨터의 브라우저 안에서만 처리됩니다.

**바로 열기:** https://j333333766-hub.github.io/pdf-tool/

## 기능

- 🗜️ PDF 용량 줄이기 (10단계 정밀 조절)
- 🧩 스마트 합치기 (PDF + 이미지)
- ✂️ 범위 분할 저장
- 📝 논서술형 평가지 분할 (학교 명렬표로 학번·이름 파일명 자동 지정)
- 🔄 페이지 회전
- 🗂️ 페이지 정리
- 🖼️ PDF → 이미지 변환
- 🔢 쪽번호 · 워터마크
- 📖 두쪽 모아찍기 → 한쪽씩 분할
- ✂️ 영역 자르기 (Crop)

## 사용 방법

위 주소로 접속하거나, `index.html`을 내려받아 브라우저로 엽니다. 라이브러리(pdf.js, pdf-lib, jsPDF, JSZip, FileSaver)를 CDN에서 불러오므로 실행할 때 인터넷 연결이 필요합니다.

## 명렬표에 관한 주의

이 저장소의 `index.html`에는 학생 명단이 들어 있지 않습니다. 앱에서 **명렬표를 포함한 앱 다운로드**로 저장한 HTML 파일에는 학생 명단이 포함되므로, 그 파일은 외부에 공유하거나 공개 저장소에 올리지 마세요.
